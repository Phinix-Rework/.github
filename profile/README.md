# Phinix Rework

**RimWorld 多人聊天、交易与可扩展插件生态**  
**Multiplayer chat, trading, and an extensible plugin ecosystem for RimWorld**

[简体中文](#简体中文) · [English](#english)

## 简体中文

欢迎来到 **Phinix Rework**！这里是 Phinix Rework 及其关联项目的统一入口。

Phinix Rework 通过独立服务器，为 RimWorld 提供殖民地间聊天、异步物品交易，以及可扩展的插件框架。围绕主项目，我们维护插件目录、分发网关、开发示例和独立扩展，让玩家与开发者更方便地参与这个生态。

### 项目导航

| 项目 | 说明 |
| --- | --- |
| [Phinix-Rework](https://github.com/HunYuan2333/Phinix-Rework) | 主项目，包含游戏客户端、独立服务端与插件框架。 |
| [Phinix-Plugin-Index](https://github.com/HunYuan2333/Phinix-Plugin-Index) | 官方插件目录，维护插件元数据、提交审核与目录发布流程。 |
| [Phinix-Plugin-Gateway](https://github.com/HunYuan2333/Phinix-Plugin-Gateway) | 基于 Cloudflare 的只读分发网关，为插件目录与发布资源提供加速访问。 |
| [Phinix-Example-Plugin](https://github.com/HunYuan2333/Phinix-Example-Plugin) | 插件开发参考示例，展示生命周期、界面扩展、设置与本地化。 |
| [Phinix-Legacy-RedPacket](https://github.com/HunYuan2333/Phinix-Legacy-RedPacket) | 旧版红包功能的独立托管插件移植项目。 |
| [Phinix-Legacy-TalentTrade](https://github.com/HunYuan2333/Phinix-Legacy-TalentTrade) | 旧版人才交易功能的独立托管插件移植项目。 |
| [Phinix-PluginStore-PoC](https://github.com/HunYuan2333/Phinix-PluginStore-PoC) | 插件运行时与商店相关功能的开发测试项目，不面向普通玩家安装。 |

### 从这里开始

- **玩家**：访问 [主项目](https://github.com/HunYuan2333/Phinix-Rework) 查看安装说明，在 [Releases](https://github.com/HunYuan2333/Phinix-Rework/releases) 获取发布包；插件可通过游戏内商店浏览与安装。
- **插件开发者**：从 [示例插件](https://github.com/HunYuan2333/Phinix-Example-Plugin) 开始，参考 [插件目录的提交说明](https://github.com/HunYuan2333/Phinix-Plugin-Index#author-submission-guide) 发布你的扩展。
- **贡献者**：欢迎在对应仓库提交 Issue 或 Pull Request，参与代码、文档与翻译改进。

目前主项目面向 **RimWorld 1.6**。各扩展的兼容性、依赖与发布状态，请以对应仓库说明和插件目录为准。

## English

Welcome to **Phinix Rework**! This organization serves as a shared entry point for Phinix Rework and its related projects.

Phinix Rework brings inter-colony chat, asynchronous item trading, and an extensible plugin framework to RimWorld through a dedicated server. Alongside the main project, we maintain a plugin catalog, a distribution gateway, development examples, and standalone extensions to help players and developers participate in the ecosystem.

### Projects

| Project | Description |
| --- | --- |
| [Phinix-Rework](https://github.com/HunYuan2333/Phinix-Rework) | The main project, including the game client, dedicated server, and plugin framework. |
| [Phinix-Plugin-Index](https://github.com/HunYuan2333/Phinix-Plugin-Index) | The official plugin catalog, with package metadata, submission review, and catalog publication workflows. |
| [Phinix-Plugin-Gateway](https://github.com/HunYuan2333/Phinix-Plugin-Gateway) | A read-only Cloudflare distribution gateway providing accelerated access to catalog metadata and release assets. |
| [Phinix-Example-Plugin](https://github.com/HunYuan2333/Phinix-Example-Plugin) | A reference plugin demonstrating lifecycle management, UI extensions, settings, and localization. |
| [Phinix-Legacy-RedPacket](https://github.com/HunYuan2333/Phinix-Legacy-RedPacket) | A standalone managed plugin port of the legacy red-packet feature. |
| [Phinix-Legacy-TalentTrade](https://github.com/HunYuan2333/Phinix-Legacy-TalentTrade) | A standalone managed plugin port of the legacy talent-trading feature. |
| [Phinix-PluginStore-PoC](https://github.com/HunYuan2333/Phinix-PluginStore-PoC) | A development test project for the plugin runtime and store-related functionality, not intended for regular player installation. |

### Get started

- **Players**: Visit the [main project](https://github.com/HunYuan2333/Phinix-Rework) for installation instructions and download packages from [Releases](https://github.com/HunYuan2333/Phinix-Rework/releases). Browse and install plugins through the in-game store.
- **Plugin authors**: Start with the [example plugin](https://github.com/HunYuan2333/Phinix-Example-Plugin), then follow the [catalog submission guide](https://github.com/HunYuan2333/Phinix-Plugin-Index#author-submission-guide) to publish your extension.
- **Contributors**: Issues and pull requests are welcome in the relevant repositories, including improvements to code, documentation, and translations.

The main project currently targets **RimWorld 1.6**. For each extension's compatibility, dependencies, and release status, refer to its repository and the plugin catalog.
